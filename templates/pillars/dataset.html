Chinese Tea Dataset

A free, structured dataset of {{ tea_count }} Chinese teas. Use it for research, apps, visualizations, or tea education projects.

Scope and Limitations

This is a descriptive reference dataset, not a laboratory or product certification dataset. Caffeine and oxidation values are unverified estimates. Flavor and origin descriptions can vary by producer and batch. The current tea records have no per-record source citations. The tier field describes data completeness, not tea quality.

The export contains the fields listed below; it does not include measured caffeine doses or brewing parameters. Flavor notes are comma-separated text in both formats. The generated timestamp records export time, not editorial review.

For responsible use, read the caffeine evidence and check claims against primary sources before publishing conclusions. Send a correction with its source.

Fields

What's Included

  • id — URL-safe identifier
  • name_en — English name
  • name_zh — Chinese name
  • category — Green, oolong, black, pu'er, white, yellow, dark, scented
  • region — Production region
  • caffeine_level — Unverified qualitative label; not a measured dose
  • body — Light, medium, full, etc.
  • oxidation_level — Estimated fraction from 0 to 1; not a laboratory measurement
  • flavor_primary — Primary flavor notes
  • description_brief — Short description
  • tier — Data completeness tier
