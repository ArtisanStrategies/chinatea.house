# Chinese Tea Caffeine Reference

[Open the chart](https://chinatea.house/chinese-tea-caffeine-chart/). It counts unverified qualitative labels in the reference dataset. Counts do not measure caffeine concentration or establish category rankings. None of the tea records currently contains a per-record source citation.

Use the [caffeine guide](https://chinatea.house/guide/caffeine-in-chinese-tea/) for scoped primary research and practical limitations. Obtain product-specific test information for dose-sensitive decisions. The finder matches flavor and mouthfeel, not caffeine dose.
